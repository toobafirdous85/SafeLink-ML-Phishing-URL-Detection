# Outputs

This directory contains selected outputs generated during the Week 2 data preprocessing and feature engineering stage of the SafeLink project.

The outputs provide supporting evidence for the preprocessing decisions documented in the Week 2 report.

## Planned Output Categories

### Dataset Inspection

Outputs related to:

* Dataset dimensions
* Data types
* Highly correlated feature pairs
* Data quality observations

### Data Cleaning

Outputs related to:

* Missing-value analysis
* Duplicate record analysis
* Duplicate URL analysis
* Conflicting URL labels
* Target distribution

### Feature Engineering

Outputs related to:

* Removed redundant features
* Feature skewness analysis
* Numerical transformation analysis
* Scaling verification
* Categorical feature analysis
* TLD frequency and grouping

### Final Dataset

Outputs documenting:

* Final feature dimensions
* Encoded feature structure
* Remaining categorical/object columns
* Train-test split dimensions
* Target distribution across training and testing sets

Only relevant and meaningful analysis artifacts will be retained in this directory. Large intermediate datasets are intentionally excluded from the repository.
